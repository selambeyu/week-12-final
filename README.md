# Knowledge gap research — Week 12

Research and artifacts for **TRP1 Week 12: Knowledge gap formulation for compounding**. This repo documents a four-day paired loop: one diagnostic gap per day, partner-reviewed explainers, call notes, sign-offs, and **grounding commits** that tighten the evidence chain on a Weeks 10–11 portfolio (a **Conversion-Engine** sales agent and **Sales-Evaluation-Bench** with a trainable critic).
